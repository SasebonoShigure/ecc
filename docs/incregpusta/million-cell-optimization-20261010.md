## 改动与检查边界

| 改动 | 保留的语义 |
|---|---|
| 捕获计划排序前缓存每条 StableArcRef 编码 | 原有候选顺序与 stable ID |
| 私有受控 native-export index 构造减少重复证明 | OFF 保留 dense ID、resolver 唯一性、binding 覆盖、session/generation；ON 证明 aggregate；公共裸 factory 仍全检 |
| sealed descriptor 复用构造时已证明的邻接成员关系 | 局部 expected-value、边界、高水位、reference/index delta 适用性；完整公共 validator 不变 |
| 末轮 scatter 在 query guard 内借用 committed ArcKey | 身份匹配、全部 parallel ordinal 和覆盖检查；不跨查询保留借用 |
| Verilog 加载本次调用内建立 IO 名称索引 | 首次匹配、bus/转义名、显式和自动 top、内部连接 |
| 起终点及断环成员查找使用本次构图局部集合 | 既有条目顺序、重复构图、三次遍历和断环选择顺序 |
| Verilog 追加句柄，native net/load 用局部索引去重 | C view 生命周期、首次出现顺序、旧 driver/net 清理 |
| 无待推断 inout 时删除预备 cell graph | 最终图仍清空重建；有 inout 时仍构造预备图并推断 |
| 导入器和 Verilog 解析树使用独占所有权 | 借用 C view 仅在解析器存活时使用，重读清空旧视图；IDB 导入结果在解析器销毁后仍有效 |
| 末轮 native 视图复用局部拓扑 patch（第十三版候选） | 仅更新新增 buffer、改接弧和受影响邻接；保留完整权威 timing 发布、撤销与查询重试；native CPU/full 仍完整构图 |

第九版针对性检查、小规模公开结果比较、两设计三模式单批预检、完整 OFF/ON/无 CUDA native、parent 及 CUDA 内存回归已通过；正式十批采样未开始。第十版修复加载结束仍保留解析树的所有权缺口，完整 OFF/ON/无 CUDA native、隔离 binding、parent 409 项和 CUDA 内存回归通过，CPU sanitizer 仍有下述泄漏。未改变时序数值容差、模式、算法必需工作或诊断开关。共同 host 优化同样改善 CPU/full，横向比较必须使用同版本 CPU。
